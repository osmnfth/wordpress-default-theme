# Κοσμητεία Σχολών — WordPress theme + έτοιμο περιβάλλον

Δίγλωσσο (EL/EN) **child theme του Twenty Twenty-Five** για ιστοσελίδες Κοσμητείας
Σχολών, μαζί με πλήρες περιβάλλον Docker που στήνει μόνο του ένα λειτουργικό site
με δοκιμαστικό περιεχόμενο.

```
.
├─ kosmiteia/          → το theme (αυτό αντιγράφετε σε ένα πραγματικό WordPress)
├─ docker-compose.yml  → WordPress + MariaDB + αυτόματο provisioning
└─ docker/             → script στησίματος, δοκιμαστικό περιεχόμενο, εικόνες
```

---

## 1. Γρήγορη εκκίνηση

```bash
docker compose up -d
```

Την πρώτη φορά κατεβαίνουν οι εικόνες και στήνεται το site (~2 λεπτά). Μετά:

| | |
|---|---|
| Ιστότοπος | http://localhost:8090 |
| Αγγλική έκδοση | http://localhost:8090/?lang=en |
| Διαχείριση | http://localhost:8090/wp-admin |
| Στοιχεία | `admin` / ο κωδικός του `.env` (`KOSMITEIA_ADMIN_PASSWORD`, προεπιλογή `admin`) |

Ο φάκελος `kosmiteia/` είναι συνδεδεμένος (mounted) μέσα στο container: κάθε αλλαγή
που κάνετε τοπικά φαίνεται αμέσως με ένα refresh.

### Τι στήνεται αυτόματα

- WordPress (τελευταία έκδοση) με **ελληνικά** ως γλώσσα διεπαφής
- Twenty Twenty-Five (parent) + ενεργοποιημένο το theme **Κοσμητεία**
- **FileBird** (φάκελοι στη Βιβλιοθήκη πολυμέσων) εγκατεστημένο και ενεργό
- Μόνιμοι σύνδεσμοι `/%postname%/`
- Δοκιμαστικό περιεχόμενο αντλημένο από τον ιστότοπο της **Κοσμητείας της Σχολής
  Επιστημών Υγείας Δ.Π.Θ.** ([health.duth.gr](https://health.duth.gr/)): **3 Τμήματα**
  (Ιατρικής, Μοριακής Βιολογίας & Γενετικής, Νοσηλευτικής), **6 Ανακοινώσεις**,
  **6 Μεταπτυχιακά**, σελίδες «Η Κοσμητεία», «Μήνυμα Κοσμήτορα», «Πρόσβαση» και
  «Επικοινωνία» (οι δύο τελευταίες με χάρτη Leaflet στην Πανεπιστημιούπολη Δραγάνας)
- **Αναζήτηση και φίλτρα** στις Ανακοινώσεις (κείμενο, κατηγορία, Σχολή, έτος) με
  σελιδοποίηση που κρατά τα φίλτρα
- 13 εικόνες, λογότυπο, φωτογραφίες hero
- **Δύο μενού**: `main` (EL) και `main-en` (EN)
- **Αγγλικά template parts**: `header-en`, `footer-en`, `home-hero-en`, `home-schools-en`,
  `home-announcements-en`, `home-programs-en` — παράγονται από τα patterns του theme
  στα αγγλικά, οπότε το `?lang=en` δίνει αμέσως αγγλική κεφαλίδα, υποσέλιδο και ενότητες

### Καθημερινές εντολές

```bash
docker compose down                              # σταμάτημα (κρατά τη βάση)
docker compose down -v                           # σβήσιμο όλων και καθαρό ξεκίνημα
docker compose logs -f provision                 # τι έκανε το στήσιμο
docker compose run --rm -e KOSMITEIA_RESEED=1 provision   # ξαναχτίσιμο περιεχομένου
docker compose run --rm provision wp plugin list          # οποιαδήποτε εντολή WP-CLI
```

Αλλαγή θύρας ή κωδικού (πριν το πρώτο `up`):

```bash
KOSMITEIA_PORT=9000 KOSMITEIA_ADMIN_PASSWORD=secret docker compose up -d
```

> Όταν αλλάξει το `docker/seed.php`, ανεβάστε το `KOSM_DEMO_VERSION` ώστε το
> περιεχόμενο να ξαναχτιστεί στο επόμενο `up`, ή τρέξτε το με `KOSMITEIA_RESEED=1`.
> Το reseed **ενημερώνει** τα υπάρχοντα άρθρα (ίδιο slug) και δεν σβήνει παλιά:
> για εντελώς καθαρό αποτέλεσμα χρησιμοποιήστε `docker compose down -v`.

> Το `provision` container τρέχει μία φορά και τερματίζει — αυτό είναι φυσιολογικό.
> Είναι idempotent: δεν ξαναγράφει περιεχόμενο αν υπάρχει ήδη.

## 2. Εγκατάσταση σε πραγματικό WordPress

Αντιγράψτε **μόνο** τον φάκελο `kosmiteia/` στο `wp-content/themes/` και ενεργοποιήστε
το από **Εμφάνιση → Θέματα**. Απαιτείται εγκατεστημένο το Twenty Twenty-Five.
Αναλυτικές οδηγίες, δομή και δυνατότητες: [kosmiteia/README.md](kosmiteia/README.md).

---

## 3. Δοκιμασμένο

Το theme δοκιμάστηκε σε **WordPress 7.1** (PHP 8.3, MariaDB 11):

- Αρχείο Ανακοινώσεων: αναζήτηση, φίλτρα κατηγορίας / Σχολής / έτους, μετρητής
  αποτελεσμάτων και σελιδοποίηση `/announcements/page/2/?kosm_year=2026` που κρατά
  τις παραμέτρους — και στα Αγγλικά (`?lang=en`)
- Χάρτης Leaflet στη σελίδα Επικοινωνίας: πλακίδια και πινέζα φορτώνουν κανονικά,
  με εναλλακτική εμφάνιση όταν λείπει το JavaScript

- Αρχική, αρχεία και μεμονωμένες σελίδες Σχολών / Ανακοινώσεων / Μεταπτυχιακών:
  HTTP 200, χωρίς PHP warnings
- Εναλλαγή γλώσσας EL/EN: `lang` attribute, μενού, κεφαλίδα, υποσέλιδο και ενότητες
- Όλα τα templates και template parts (EL και EN) ανοίγουν στον **Site Editor χωρίς
  κανένα σφάλμα επικύρωσης μπλοκ** — δηλαδή όλα επεξεργάζονται κανονικά από το UI
- Block Bindings (διάρκεια, ECTS, σύνδεσμος αίτησης, συνημμένα) εμφανίζονται σωστά
- Structured data: `CollegeOrUniversity`, `Course`, `NewsArticle`,
  `EducationalOrganization`, `BreadcrumbList`
