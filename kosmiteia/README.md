# Κοσμητεία — Kosmiteia

Δίγλωσσο (Ελληνικά / Αγγλικά) **child theme του Twenty Twenty-Five** για ιστοσελίδες
Κοσμητείας Σχολών. Όλο το περιεχόμενο είναι δυναμικό (custom post types + Query Loops)
και κάθε ενότητα επεξεργάζεται από το UI (Site Editor), χωρίς κώδικα.

---

## 0. Δοκιμή με ένα κλικ (Docker)

Στη ρίζα του αποθετηρίου υπάρχει έτοιμο περιβάλλον:

```bash
docker compose up -d       # http://localhost:8090  (admin / admin)
```

Στήνει WordPress στα ελληνικά, ενεργοποιεί το theme και δημιουργεί δοκιμαστικό
περιεχόμενο, μενού και τα αγγλικά template parts. Λεπτομέρειες: [../README.md](../README.md).

---

## 1. Εγκατάσταση

1. Το **Twenty Twenty-Five** πρέπει να είναι εγκατεστημένο (δεν χρειάζεται να είναι ενεργό).
2. Αντιγράψτε τον φάκελο `kosmiteia/` στο `wp-content/themes/`.
3. **Εμφάνιση → Θέματα → Ενεργοποίηση** «Κοσμητεία — Kosmiteia».
4. **Ρυθμίσεις → Μόνιμοι σύνδεσμοι → Αποθήκευση** (μία φορά, για τα permalinks των CPT).
5. **Ρυθμίσεις → Ανάγνωση**: επιλέξτε στατική αρχική σελίδα (προαιρετικό — το
   `front-page.html` χρησιμοποιείται σε κάθε περίπτωση).

Δοκιμασμένο σε WordPress 7.1. Απαιτήσεις: WordPress 6.6+ (τα Block Bindings θέλουν 6.5+, η επεξεργασία τιμών meta
μέσα από τα μπλοκ 6.7+), PHP 7.4+.

## 2. Πού γράφεται το περιεχόμενο

| Ενότητα αρχικής | Από πού τροφοδοτείται | Μενού διαχείρισης |
|---|---|---|
| Hero slider | Το ίδιο το template part (μπλοκ Cover ανά διαφάνεια) | Εμφάνιση → Επεξεργαστής → Πρότυπα/Parts |
| Σχολές | Custom post type **Σχολές** | Σχολές |
| Ανακοινώσεις | Custom post type **Ανακοινώσεις** | Ανακοινώσεις |
| Μεταπτυχιακά | Custom post type **Μεταπτυχιακά** | Μεταπτυχιακά |
| Header / Subfooter | Template parts | Εμφάνιση → Επεξεργαστής → Patterns → Template parts |

**Κανένα κείμενο δεν είναι «κλειδωμένο» στον κώδικα**: ό,τι βλέπετε στην αρχική είναι
μπλοκ που αλλάζετε από τον Site Editor.

### Custom post types & taxonomies

- `kosm_school` — Σχολές (τίτλος, περιγραφή, περίληψη, φωτογραφία, σειρά)
- `kosm_announcement` — Ανακοινώσεις (+ κατηγορίες `kosm_ann_category`)
- `kosm_program` — Μεταπτυχιακά (+ τύποι `kosm_program_type`)
- `kosm_faculty` — κοινή ταξινομία «Σχολή», συνδέει ανακοινώσεις/προγράμματα με μια Σχολή

### Πεδία (post meta) μέσω Block Bindings

Τα πρότυπα `single-kosm_program.html`, `single-kosm_school.html` και
`single-kosm_announcement.html` περιέχουν μπλοκ συνδεδεμένα με πεδία:

- Πρόγραμμα: `kosm_duration`, `kosm_ects`, `kosm_fees`, `kosm_deadline`, `kosm_director`, `kosm_apply_url`
- Σχολή: `kosm_dean`, `kosm_phone`, `kosm_email`, `kosm_address`, `kosm_site_url`
- Ανακοίνωση: `kosm_deadline`, `kosm_file_url`
- Όλα: `kosm_gallery` — οι φωτογραφίες της γκαλερί, από το πλαίσιο «Φωτογραφίες
  (γκαλερί)» κάτω από το κείμενο (δείτε §5.5)

Συμπληρώνονται γράφοντας απευθείας μέσα στο μπλοκ (WP 6.7+) ή από το panel
«Προσαρμοσμένα πεδία».

## 3. Πολυγλωσσία (EL / EN)

Το theme δουλεύει σε τρία επίπεδα — διαλέξτε ό,τι σας ταιριάζει:

### α) Με Polylang ή WPML (πλήρης μετάφραση περιεχομένου — προτεινόμενο)

Εγκαταστήστε το plugin και ορίστε Ελληνικά + Αγγλικά. Το μπλοκ **Επιλογέας γλώσσας**
παίρνει αυτόματα τις γλώσσες, τα URL και την τρέχουσα γλώσσα από το plugin. Στις
ρυθμίσεις του Polylang ενεργοποιήστε τα custom post types και τις taxonomies του theme.

### β) Χωρίς plugin (ενσωματωμένο fallback)

Το `?lang=en` αλλάζει το locale: όλα τα κείμενα του theme, οι ετικέτες, οι ημερομηνίες
και το `lang` attribute γίνονται αγγλικά (μεταφράσεις στο `languages/en_US.mo`).
Η επιλογή αποθηκεύεται σε cookie.

### γ) Αγγλικές εκδόσεις κεφαλίδας, υποσέλιδου και ενοτήτων

Όταν η τρέχουσα γλώσσα είναι τα Αγγλικά, το theme προτιμά αυτόματα:

- **template part** με slug `<slug>-en` (π.χ. `header-en`, `footer-en`, `home-hero-en`)
- **μενού πλοήγησης** με slug `<slug>-en` (π.χ. `main-en`)

Δημιουργήστε τα από **Εμφάνιση → Επεξεργαστής → Patterns → Template parts → Προσθήκη**,
με τίτλο π.χ. «Header EN». Αν δεν υπάρχουν, εμφανίζεται κανονικά η ελληνική έκδοση.

> Συμβουλή: αλλάξτε τη γλώσσα του προφίλ σας σε English και τα patterns «Κοσμητείας»
> εισάγονται στα αγγλικά — ιδανικό για να χτίσετε γρήγορα τα `-en` parts.

Επίσης παράγονται αυτόματα `hreflang` links σε κάθε σελίδα.

## 5. Μπλοκ & στυλ του theme

- **Slider (Κοσμητεία)** — κάθε διαφάνεια είναι κανονικό μπλοκ Cover: βάλτε φωτογραφία
  **ή βίντεο** φόντου, τίτλο και κουμπιά. Ρυθμίσεις: αυτόματη εναλλαγή, διάρκεια, βέλη,
  κουκκίδες, εφέ (κύλιση/fade), aria-label.
- **Επιλογέας γλώσσας** — σύντομες ή πλήρεις ετικέτες, οριζόντια ή αναδυόμενη διάταξη.
- **Φίλτρα ανακοινώσεων** — αναζήτηση κειμένου + φίλτρα κατηγορίας, Σχολής και έτους
  για το αρχείο Ανακοινώσεων (δείτε §5.1).
- **Χάρτης (Leaflet)** — διαδραστικός χάρτης OpenStreetMap για τη σελίδα Επικοινωνίας
  (δείτε §5.2).
- **Διαδρομή πλοήγησης** — breadcrumbs `Αρχική › ενότητα › σελίδα` (δείτε §5.3).
- **Γκαλερί εικόνων** — μικρογραφίες σε responsive γραμμή με εφέ hover και lightbox·
  οι φωτογραφίες ορίζονται στο πεδίο «Φωτογραφίες (γκαλερί)» της σελίδας (δείτε §5.5).
- **Στυλ μπλοκ**: «Κάρτες Κοσμητείας», «Κάρτα με σκιά», «Subfooter 4 στηλών»,
  «Κουμπί κύλισης», «Zoom στο hover», «Με υπογράμμιση».
- **Patterns** (κατηγορία «Κοσμητεία»): Hero slider, Σχολές σε κάρτες, Πρόσφατες
  ανακοινώσεις, Μεταπτυχιακά, Subfooter 4 στηλών, Κεφαλίδα, Επικοινωνία: στοιχεία και χάρτης.
- **Παραλλαγή στυλ**: «Σκούρο ακαδημαϊκό» (Εμφάνιση → Επεξεργαστής → Στυλ).
- **Πολυμέσα**: αυτόματη μετατροπή εικόνων σε WebP, βίντεο μόνο σε WebM, φάκελοι
  αρχείων με FileBird (δείτε §5.6).

### 5.1 Αναζήτηση και φίλτρα στις Ανακοινώσεις

Το `templates/archive-kosm_announcement.html` περιέχει το μπλοκ **Φίλτρα ανακοινώσεων**
πάνω από το Query Loop. Τα φίλτρα γράφονται στο URL, οπότε κάθε συνδυασμός
μοιράζεται και μπαίνει στους σελιδοδείκτες:

| Παράμετρος | Παράδειγμα | Τι κάνει |
|---|---|---|
| `kosm_q` | `?kosm_q=erasmus` | αναζήτηση σε τίτλο και περιεχόμενο |
| `kosm_cat` | `?kosm_cat=<slug>` | κατηγορία ανακοίνωσης (`kosm_ann_category`) |
| `kosm_fac` | `?kosm_fac=<slug>` | Σχολή (`kosm_faculty`) |
| `kosm_year` | `?kosm_year=2026` | έτος δημοσίευσης |

Τα ονόματα είναι επίτηδες «δικά μας»: το `?kosm_school` θα το ερμήνευε το WordPress ως
μεμονωμένη Σχολή και το `?kosm_faculty` ως αρχείο ταξινομίας, αλλάζοντας το πρότυπο.

Τα φίλτρα εφαρμόζονται στο **κύριο query** (`pre_get_posts`), άρα το Query Loop
δουλεύει με «Κληρονομιά ερωτήματος» και η σελιδοποίηση (`/announcements/page/2/`)
**κρατά τα φίλτρα** αυτόματα. Τα πεδία που εμφανίζονται ρυθμίζονται από τον editor
(Ρυθμίσεις μπλοκ → Πεδία φίλτρων).

Ανακοινώσεις ανά σελίδα (προεπιλογή 4):

```php
add_filter( 'kosmiteia_announcements_per_page', function () { return 12; } );
```

Χωρίς JavaScript η φόρμα δουλεύει κανονικά με το κουμπί «Φιλτράρισμα». Με JavaScript
τα άδεια πεδία δεν μπαίνουν στο URL και η αλλαγή σε λίστα υποβάλλει αμέσως τη φόρμα.

### 5.2 Χάρτης (Leaflet)

Το μπλοκ **Χάρτης (Leaflet)** μπαίνει σε οποιαδήποτε σελίδα (οι σελίδες «Επικοινωνία»
και «Πρόσβαση» του δοκιμαστικού περιεχομένου το έχουν ήδη).

**Πού μπαίνουν οι συντεταγμένες:** μέσα στο ίδιο το μπλοκ, στα πεδία «Γεωγραφικό
πλάτος», «Γεωγραφικό μήκος», «Τίτλος πινέζας» και «Διεύθυνση» — είναι πάντα ορατά
στον editor, χωρίς να χρειάζεται η πλαϊνή στήλη. Τα ίδια πεδία, μαζί με **ζουμ,
ύψος, ζουμ με ρόδα ποντικιού και σύνδεσμο οδηγιών**, υπάρχουν και στις ρυθμίσεις
του μπλοκ (εικονίδιο ⚙ πάνω δεξιά → καρτέλα «Μπλοκ»). Τις συντεταγμένες ενός
σημείου τις βρίσκετε με δεξί κλικ στο openstreetmap.org → «Show address».

- Η **Leaflet 1.9.4 συνοδεύει το theme** (`assets/vendor/leaflet/`): δεν φορτώνεται
  τίποτα από CDN και τα αρχεία μπαίνουν στη σελίδα μόνο όταν υπάρχει μπλοκ χάρτη.
- Ο χάρτης στήνεται μόλις πλησιάσει στο viewport, οπότε δεν ζητούνται πλακίδια από
  το OpenStreetMap αν ο επισκέπτης δεν φτάσει ποτέ σε αυτόν.
- Χωρίς JavaScript (ή χωρίς δίκτυο) εμφανίζονται η διεύθυνση και σύνδεσμοι προς τον
  χάρτη και τις οδηγίες πρόσβασης — το ίδιο ισχύει και στην εκτύπωση.
- Στον Site Editor εμφανίζεται σύνοψη αντί για ζωντανό χάρτη, ώστε η επεξεργασία να
  μένει γρήγορη.

Για δικό σας tile server (π.χ. του Ιδρύματος):

```php
add_filter( 'kosmiteia_map_tile_url', function () { return 'https://tiles.example.edu/{z}/{x}/{y}.png'; } );
add_filter( 'kosmiteia_map_attribution', function () { return 'Πηγή χάρτη: Example'; } );
```

### 5.3 Κεφαλίδα εσωτερικής σελίδας & breadcrumbs

Το `templates/page.html` δίνει σε κάθε **σελίδα** μια κεφαλίδα με:

- **φωτογραφία φόντου = η επιλεγμένη εικόνα της σελίδας**. Την ανεβάζετε ανά σελίδα από
  τη δεξιά στήλη του επεξεργαστή: **Σελίδα → Επιλεγμένη εικόνα**. Χωρίς εικόνα, η
  κεφαλίδα γίνεται συμπαγής χρωματική ταινία (η σκίαση περνά αυτόματα στο 100%, ώστε τα
  λευκά γράμματα να διαβάζονται).
- τη **διαδρομή πλοήγησης** και τον **τίτλο** της σελίδας.

Το ύψος είναι `clamp(180px, 26vw, 300px)` και σε κινητά η κεφαλίδα «μαζεύει» στο ύψος
του περιεχομένου της, με τον τίτλο σε `clamp(1.75rem, 7vw, 2.5rem)`.

Το μπλοκ **Διαδρομή πλοήγησης** υπάρχει επίσης στα πρότυπα αρχείων και στις μεμονωμένες
Σχολές / Ανακοινώσεις / Μεταπτυχιακά. Χτίζεται μόνο του:

| Σελίδα | Διαδρομή |
|---|---|
| Σελίδα | Αρχική › (γονικές σελίδες) › Σελίδα |
| Ανακοίνωση | Αρχική › Ανακοινώσεις › Κατηγορία › Τίτλος |
| Σχολή / Πρόγραμμα | Αρχική › Αρχείο › Τίτλος |
| Αρχείο ή ταξινομία | Αρχική › Όνομα αρχείου |

Η ίδια συνάρτηση (`kosmiteia_breadcrumb_trail()`) τροφοδοτεί και το `BreadcrumbList`
του JSON-LD, οπότε ορατή διαδρομή και structured data δεν διαφωνούν ποτέ.

### 5.4 Μενού σε κινητά

Στο overlay του «χάμπουργκερ»: στοιχεία κεντραρισμένα σε πλήρες πλάτος, στόχοι αφής
44px και **υπομενού κλειστά με βελάκι** — ανοίγουν με κλικ ή tap στο βελάκι, ενώ ο
σύνδεσμος του γονέα παραμένει κανονικός σύνδεσμος. Χωρίς JavaScript τα υπομενού
εμφανίζονται ανοιχτά (συμπεριφορά του πυρήνα), οπότε τίποτα δεν χάνεται.

### 5.5 Γκαλερί φωτογραφιών & lightbox

Οι φωτογραφίες της γκαλερί επιλέγονται σε **δικό τους πεδίο**, όχι μέσα στο κείμενο:
στην οθόνη επεξεργασίας (Σχολή, Μεταπτυχιακό, Ανακοίνωση, σελίδα, άρθρο) υπάρχει το
πλαίσιο **«Φωτογραφίες (γκαλερί)»** κάτω από το κείμενο, με κουμπί «Επιλογή
φωτογραφιών» (Βιβλιοθήκη πολυμέσων), αλλαγή σειράς με ◀ ▶ και αφαίρεση με ×.

Έτσι οι φωτογραφίες της γκαλερί είναι **τελείως ξεχωριστές** από τις εικόνες που
μπαίνουν μέσα στο κείμενο και από την επιλεγμένη εικόνα (featured) — καμία εικόνα
δεν εμφανίζεται δύο φορές. Αποθηκεύονται στο meta `kosm_gallery` (IDs χωρισμένα με
κόμμα) και είναι διαθέσιμες και μέσω REST API.

Το μπλοκ **Γκαλερί εικόνων** απλώς τυπώνει το πεδίο της σελίδας στην οποία
εμφανίζεται· στις ρυθμίσεις του υπάρχει μόνο η εμφάνιση: τίτλος ενότητας, μέγιστο
πλήθος, στήλες σε μεγάλες οθόνες, κενό (gap), ελάχιστο πλάτος μικρογραφίας
(καθορίζει πόσες χωρούν στο κινητό), αναλογίες (1:1, 4:3, 3:2, 16:9, 3:4, φυσικές)
και λεζάντες. Χωρίς φωτογραφίες στο πεδίο, το μπλοκ δεν τυπώνει τίποτα.

Στο hover/focus η μικρογραφία ανασηκώνεται, η εικόνα κάνει ελαφρύ zoom και
εμφανίζεται εικονίδιο μεγέθυνσης. Με κλικ ανοίγει lightbox (σαν Colorbox, αλλά
χωρίς jQuery — δικό μας `assets/js/lightbox.js`, φορτώνεται μόνο όπου υπάρχει
γκαλερί) με βελάκια, μετρητή, λεζάντα, πλοήγηση με ← →, κλείσιμο με Escape ή κλικ
έξω από την εικόνα, σύρσιμο στο κινητό και επιστροφή του focus στη μικρογραφία.
Χωρίς JavaScript κάθε μικρογραφία παραμένει απλός σύνδεσμος προς την εικόνα.

Η σελίδα Σχολής (`templates/single-kosm_school.html`) έχει ήδη τη γκαλερί **κάτω από
το κείμενο** (μετά τις στήλες περιεχομένου/επικοινωνίας και πριν από τις
ανακοινώσεις), με τίτλο «Φωτογραφίες». Η παλιά μεγάλη φωτογραφία (featured) δεν
εμφανίζεται πια στη σελίδα.

Ποιοι τύποι περιεχομένου έχουν το πεδίο:

```php
add_filter( 'kosmiteia_gallery_post_types', function ( $types ) {
	return array( 'kosm_school' );
} );
```

### Σχετικές ανακοινώσεις σε σελίδα Σχολής

Σε ένα Query Loop μέσα σε σελίδα Σχολής, προσθέστε την κλάση CSS
`is-related-to-school` (Ρυθμίσεις μπλοκ → Για προχωρημένους). Το query φιλτράρεται
αυτόματα με τη Σχολή της τρέχουσας σελίδας.

### 5.6 Πολυμέσα: WebP, WebM και φάκελοι (FileBird)

**Εικόνες → WebP.** Κάθε JPEG/PNG που ανεβαίνει μετατρέπεται σε WebP: και το
πρωτότυπο και όλα τα παραγόμενα μεγέθη. Δουλεύει και για τα αρχεία που μπαίνουν
προγραμματιστικά (import / sideload). Τα GIF μένουν ως έχουν (η μετατροπή χάνει το
animation) και τα AVIF δεν πειράζονται (είναι ήδη πιο αποδοτικά από WebP).

Για τη βιβλιοθήκη που υπάρχει ήδη: **Πολυμέσα → προβολή λίστας → επιλογή αρχείων →
Μαζικές ενέργειες → «Μετατροπή σε WebP»**. Τα URL μέσα στο περιεχόμενο των σελίδων
ενημερώνονται αυτόματα, και τα παλιά αρχεία μένουν στον δίσκο ώστε να μη σπάσει
τίποτα που δείχνει σε αυτά χειροκίνητα.

**Βίντεο → WebM.** Το WordPress δεν μπορεί να μετατρέψει βίντεο (χρειάζεται
ffmpeg), οπότε τα βίντεο γίνονται δεκτά μόνο σε `.webm`· σε οτιδήποτε άλλο η
μεταφόρτωση σταματά με σαφές μήνυμα.

Ρυθμίσεις:

```php
add_filter( 'kosmiteia_webp_quality', function () { return 90; } );   // ποιότητα (82)
add_filter( 'kosmiteia_convert_uploads_to_webp', '__return_false' );  // χωρίς WebP
add_filter( 'kosmiteia_require_webm_video', '__return_false' );       // δεκτά όλα τα βίντεο
```

Αν ο server δεν έχει GD/Imagick με WebP, η μετατροπή απενεργοποιείται μόνη της και
τα αρχεία ανεβαίνουν όπως είναι.

**Φάκελοι στη Βιβλιοθήκη πολυμέσων:** το site χρησιμοποιεί το πρόσθετο **FileBird**
(δωρεάν έκδοση από το wordpress.org) για δομή φακέλων στα αρχεία. Εγκαθίσταται
αυτόματα στο περιβάλλον Docker· σε κανονικό site: **Πρόσθετα → Προσθήκη → FileBird
→ Εγκατάσταση**. Οι φάκελοι είναι δικό του taxonomy, οπότε το theme δεν εξαρτάται
από αυτό: αν απενεργοποιηθεί, τα αρχεία παραμένουν όλα στη θέση τους.

## 6. SEO

- `<meta name="description">`, Open Graph, Twitter cards
- JSON-LD: `CollegeOrUniversity`, `WebSite` + SearchAction, `NewsArticle` (ανακοινώσεις),

## 7. Προσβασιμότητα

- Slider κατά το APG carousel pattern: `role="region"`, `aria-roledescription`,
  κουμπιά με ετικέτες, παύση σε hover/focus, πλοήγηση με βελάκια, `inert` στις κρυφές
  διαφάνειες, σεβασμός στο `prefers-reduced-motion`.
- Ορατό focus σε όλα τα διαδραστικά στοιχεία, στόχοι αφής ≥ 44px.
- Landmarks (`header`, `main`, `footer`, `section`), σωστή ιεραρχία επικεφαλίδων,
  skip link, `screen-reader-text`, `aria-label` στα «Περισσότερα» των καρτών.
- Χωρίς JavaScript όλα παραμένουν αναγνώσιμα (progressive enhancement).
- Υποστήριξη `forced-colors` και print styles.

## 8. Μεταφράσεις — ενημέρωση

Μετά από αλλαγές σε κείμενα PHP:

```bash
cd wp-content/themes/kosmiteia
python build-translations.py
```

Παράγει ξανά τα `languages/kosmiteia.pot`, `languages/en_US.po` και `languages/en_US.mo`.
Οι αγγλικές αποδόσεις βρίσκονται στο dictionary `EN` μέσα στο `build-translations.py`.
